==================
How the web works 
==================

This thing is done by us: 
You ---> Chrome ---> Server IP ---> HTTP/HTTPS request ---> web server ---> HTTP responese ---> Chrome ---> HTML/CSS/JS ---> Rendered webpage 


How would the JS do:
Page loads --> HTML --> JS executes --> fetch --> HTTP request --> Backend --> JSON responese --> JS processess JSON --> Page changes

================================
Lesson 1 — Getting into DevTools
================================

First mission: Open a normal website you use frequently.
Then: F12 → Network

options: [document,stylesheet, script, image, font, xhr, fetch, ...]

Loading a webpage involves many network requests, not just one request.

Browser
   │
   ├── GET /                 → HTML
   ├── GET /style.css       → CSS
   ├── GET /app.js           → JavaScript
   ├── GET /logo.png        → image
   ├── GET /font.woff2      → font
   ├── GET /api/products     → data
   └── ...
