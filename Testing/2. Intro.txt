========== New concept: Decision table testing 

A user gets free shipping if:

-- they are a premium member AND
---their order is ₹500 or more.

Otherwise, shipping is charged.

| Premium? | Order ≥ ₹500? | Expected          |
| -------- | ------------- | ----------------- |
| No       | No            | No free shipping  |
| No       | Yes           | No free shipping  |
| Yes      | No            | No free shipping  |
| Yes      | Yes           | Free shipping     |
