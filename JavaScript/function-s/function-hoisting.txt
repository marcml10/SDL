                                                            |           |
                                                            |  Mind map |
                                                            |___________|

                                                1. Function declaration

                                                function greet() {}
                                                greet();

                                                → Function is available before its position
                                                → Works


                                                2. var + function expression

                                                greet();
                                                var greet = function () {};

                                                → greet is undefined initially
                                                → Calling undefined → TypeError


                                                3. let/const + function expression

                                                greet();
                                                let greet = function () {};

                                                → binding is in TDZ
                                                → ReferenceError


                                                4. After let/const initialization

                                                const greet = function () {};
                                                greet();

                                                → binding contains the function
                                                → Works


This is kind of the call stack:

--> CALL STACK

one()   ← currently executing
two()
Global


an easy example :

function one() {
    console.log("One");
}

function two() {
    console.log("Two - start");
    one();
    console.log("Two - end");
}

function three() {
    console.log("Three - start");
    two();
    console.log("Three - end");
}

three();
